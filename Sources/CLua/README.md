# CLua

The sources of [Lua 5.4.7](https://www.lua.org/ftp/lua-5.4.7.tar.gz)
(sha256 `9fbf5e28ef86c69858f6d3d34eccc32e911c1a28b4120ff3e84aaa70cfbf1e30`), unmodified: the `src` folder of the
release without `lua.c` and `luac.c` (the interpreter and the compiler), and with the public headers in `include`.
It runs the config of Inlay. License: [MIT](../../legal/third-party-license/LICENSE-Lua.txt)
