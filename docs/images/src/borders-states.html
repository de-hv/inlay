Window borders: which color

The real border layer of Inlay, drawn off screen around the windows of a sample desktop. The color comes from what the window manager knows: the focus, the floating state and the binding mode.
The focused window: active-color
The others: inactive-color
A focused floating window: floating-color
In the resize mode: the color of
[borders.mode-colors] resize = '#30D158'
inactive-color = '#00000000': only the focused window has a border (here with active-color = '#D19A66')
A dialog (a save panel, a sheet…) has no border, and with a dialog focused no window has the active color
A fullscreen window has no border, and neither have the tiled windows it covers
