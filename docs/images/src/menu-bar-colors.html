[menu-bar.colors]

Each color is '#RRGGBB', '#RRGGBBAA', 'system-accent' or 'auto': the color of the menu bar text, white on a dark bar and black on a light one. Shown in the resize mode with show-mode = true, so the accent is visible.
# The defaults [menu-bar.colors] accent = 'system-accent' focused = 'auto' occupied = 'auto' empty = 'auto'
The accent is the one of this Mac (System Settings › Appearance)
[menu-bar.colors] accent = '#E06C75' focused = '#D19A66' occupied = '#ABB2BF' empty = '#6B7280'
accent: the mode badge · focused: the focused workspace · occupied: with windows (the name, and its background at 16%) · empty: without windows. A fixed color does not adapt to the menu bar
[menu-bar.colors] focused = 'system-accent'
'system-accent' also works for focused, occupied and empty
