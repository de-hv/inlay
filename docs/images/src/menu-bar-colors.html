[menu-bar.colors]

Each color is '#RRGGBB', '#RRGGBBAA', 'system-accent' or 'auto': the color of the menu bar text, white on a dark bar and black on a light one. Shown in the resize mode with show-mode = true, so the marker of the mode is visible.
# The defaults [menu-bar.colors] accent = 'auto' focused = 'auto' occupied = 'auto' empty = 'auto'
One color that follows the menu bar. With accent = 'system-accent', the marker of a binding mode has the accent color of this Mac:
[menu-bar.colors] accent = '#E06C75' focused = '#D19A66' occupied = '#ABB2BF' empty = '#6B7280'
accent: the marker of a binding mode · focused: the focused workspace · occupied: with windows (the name, and its background at 16%) · empty: without windows. A fixed color does not adapt to the menu bar
[menu-bar.colors] focused = 'system-accent'
'system-accent' also works for focused, occupied and empty
