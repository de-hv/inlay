[menu-bar] theme

The item drawn by Inlay itself, on a dark and on a light menu bar. Workspace 2 is the focused one, and 6 is empty.
theme = 'pills'  round workspaces, and the focused one a wider pill
theme = 'chips'  the workspaces alone, as rounded squares
theme = 'square'  the names, and a square in place of the focused workspace
theme = 'minimal'  only the focused workspace
theme = 'dots'  a dot per workspace, a ring if it is empty, and the focused one a pill
theme = 'underline'  the names, and a bar under the focused one
theme = 'glyphs'  a disc per workspace with windows, a ring per empty one, and a target for the focused one
theme = 'liquid'  the default: a dot per workspace, and a drop with the name of the focused one
theme = 'segments'  a segment per workspace, hollow if it is empty, and the focused one wider, with its name before the track
theme = 'capsule'  a dot per workspace, a ring if it is empty, and a capsule with the name of the focused one
