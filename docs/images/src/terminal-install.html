==> Accessibility permission
    Inlay moves and resizes windows through the Accessibility API. The first time it opens, macOS asks
    for the permission: turn Inlay on in System Settings > Privacy & Security > Accessibility
    (it needs an administrator; on a managed Mac the list may be locked by your IT department).
    Until then Inlay does nothing: its menu bar item shows a warning sign.
    If Inlay is on in that list but still asks, remove it from the list (-) and open Inlay again.
  ✓ This build is signed with "Inlay Local Code Signing": the permission survives rebuilds.

==> Opening Inlay  /Applications/Inlay.app
    Inlay is open: look for its item in the menu bar (it has no Dock icon and no window).
    The first time, macOS asks for the Accessibility permission (see above): until you grant it, the
    item shows a warning sign and no window is moved. Once it is granted, Inlay sends the open
    windows to their workspaces and arranges them. Right-click the item for the menu and the Settings.
    The key bindings are in ~/.config/inlay/inlay.toml (inlay config --explain documents every key).
